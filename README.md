Принцип работы здесь простой:
1) Вам нужно установить Python
2) После установки Python создать папку и зайти в консоль в этой папке
3) Клонируйте Git репозиторий с помощью команды: git clone https://github.com/Egorka05284/Test_task_for_etolegko (Важно! Вам нужно иметь установленный Git и команда выполняется через Bash)
4) В консоле папки набрать команду: python -m venv venv
5) Выполнить тут же: venv\Scripts\activate
6) Устанавливаем зависимости: pip install -r requirements.txt
7) Для проверки работы скрипта выполнить: python main.py https://media.gq.com/photos/5995f31f8aaf3516506b9621/16:9/w_1920,c_limit/obi-wan-kenobi-spinoff.jpg
